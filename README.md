# Sudoku Solver
An interactive Sudoku Solver built using HTML, CSS, and JavaScript. The project solves Sudoku puzzles using a backtracking algorithm and provides a simple interface for entering and solving puzzles.

## Features
* Interactive Sudoku board
* Automatically solves Sudoku puzzles
* Validates Sudoku constraints
* Uses backtracking to find a valid solution
* Simple and responsive interface

## Technologies Used
* HTML
* CSS
* JavaScript

## How It Works
The solver uses the **backtracking algorithm** to try possible numbers in empty cells.
If a number leads to an invalid solution, the algorithm goes back and tries another possibility until the puzzle is solved.

## How to Run
1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter a Sudoku puzzle and use the solver.
